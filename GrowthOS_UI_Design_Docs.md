# GrowthOS UI 设计文档

## 0. 设计哲学

> **首页不再是"今日待办"，而是"你正在成为谁"。**

### 0.1 信息架构的根本转变

```
旧信息架构（记录工具）              新信息架构（经验管理系统）
─────────────────────              ─────────────────────
仪表盘                              成长画像
├── 今日待办                        ├── 能力雷达图（核心）
├── 记录                            ├── 本周洞察
└── 统计                            ├── 快速记录入口
                                    └── 推荐下一步
记录                                经历
└── 时间线列表                      ├── 时间线（按能力筛选）
                                    ├── 新建（结构化模板）
                                    └── 详情（event/reflection/principle）

成长树                              能力树
└── 标签云                          ├── 能力列表（按类别）
                                    ├── 能力详情（贡献经历）
                                    └── 双向操作（自上而下/自下而上）

分析                                经验网络
└── 数据图表                        ├── 原则库
                                    ├── 迁移路径
                                    └── 项目复盘
```

### 0.2 核心交互原则

| 原则           | 含义                                                |
| -------------- | --------------------------------------------------- |
| **渐进式引导** | 不要一上来就让用户填5个字段，先写"事件"再引导"反思" |
| **双向操作**   | 既能"从能力看经历"，也能"从经历看能力"              |
| **可视化优先** | 能力雷达图、成长曲线比纯文字更有冲击力              |
| **即时反馈**   | 写入经历后立即看到能力值微调、动画反馈              |
| **空状态引导** | 新用户不是空白页面，而是"你正在成为谁？"的引导      |

## 1. 视觉设计系统

### 1.1 颜色

#### 能力类别配色

| 类别                 | 主色           | 含义                 |
| -------------------- | -------------- | -------------------- |
| **思维 (Mind)**      | `#4CAF50` 绿色 | 系统思维、批判性思考 |
| **技能 (Skill)**     | `#2196F3` 蓝色 | 编程、写作、外语     |
| **认知 (Cognition)** | `#9C27B0` 紫色 | 学习方法、认知升级   |
| **体能 (Body)**      | `#FF5722` 橙色 | 运动、精力管理       |
| **社交 (Social)**    | `#FFC107` 黄色 | 沟通、领导力         |

#### 能力水平渐变

```
0   25   50   75   100
│    │    │    │    │
灰   浅   中   深   满
                    绿/蓝/紫...
```

### 1.2 字体

- **标题**：Plus Jakarta Sans, 粗体
- **正文**：Inter, 常规
- **数据**：JetBrains Mono（突出数字）

### 1.3 间距

- 卡片间距：16px
- 段落间距：24px
- 模块间距：32px

### 1.4 圆角

- 按钮：8px
- 卡片：12px
- 模态框：16px

### 1.5 动画

- **能力值变化**：500ms ease-out 过渡
- **节点生长**：300ms 弹性动画
- **页面切换**：200ms 淡入淡出

## 5. 关键场景流程

### 5.1 首次使用（空状态）

```
打开 App
  ↓
欢迎页："欢迎来到 GrowthOS —— 你正在成为谁？"
  ↓
初始化 5 大能力领域（思维/技能/认知/体能/社交）
  ↓
提示："写下你的第一个经历"
  ↓
进入 3 步引导（事件 → 反思 → 原则）
  ↓
完成 → 看到能力值 +1 的动画
  ↓
返回首页，看到能力雷达图第一笔
```

### 5.2 长期用户（10+ 经历）

```
打开 App → 成长画像
  ↓
看到本月成长曲线
  ↓
看到 "战略思维 30 天未更新" 提示
  ↓
点击 → 进入能力详情
  ↓
看到贡献经历列表
  ↓
点击"回顾 1 个月前的经验"
  ↓
回到经历详情
  ↓
AI 提示"要提炼一条新原则吗？"
```

### 5.3 项目复盘流程

```
项目标记为"完成"
  ↓
触发复盘引导：
  - 哪些能力得到了提升？
  - 哪些做得好？
  - 哪些做得不好？
  - 下次会怎么做？
  ↓
填写复盘 → 自动生成项目报告
  ↓
报告包含：
  - 能力成长（前 vs 后）
  - 提炼的经验
  - 相关原则
  ↓
存入项目历史
```

## 7. 无障碍设计

- **键盘导航**：所有交互支持 Tab 键
- **屏幕阅读器**：能力雷达图有 ARIA 标签
- **颜色对比度**：WCAG AA 标准（4.5:1）
- **字号缩放**：支持用户调整
- **动效减弱**：支持 `prefers-reduced-motion`
